Política de privacidad de Fox Run

Última actualización: 6 de octubre de 2026

1. Introducción

Esta política de privacidad explica cómo se trata la información en la aplicación móvil Fox Run.

2. Información que recopilamos

Fox Run no requiere que el usuario cree una cuenta y no solicita directamente datos personales como nombre, dirección, número de teléfono o correo electrónico.

La aplicación tampoco solicita acceso a contactos, cámara, micrófono o ubicación del dispositivo.

3. Uso de Internet

La aplicación incluye el permiso técnico de Internet proporcionado por Android. Actualmente, Fox Run no utiliza este permiso para recopilar datos personales del usuario ni para realizar seguimiento de su actividad.

4. Publicidad y análisis

Actualmente Fox Run no utiliza servicios de publicidad, análisis de terceros, Firebase, Google Analytics, AdMob ni sistemas similares de seguimiento.

5. Compartición de información

No vendemos, alquilamos ni compartimos datos personales de los usuarios con terceros, ya que la aplicación no recopila actualmente datos personales de los usuarios.

6. Datos almacenados en el dispositivo

El juego puede utilizar los recursos necesarios para su funcionamiento, como imágenes, sonidos y otros archivos propios de la aplicación. Estos recursos forman parte del juego y no constituyen datos personales del usuario.

7. Seguridad

Tomamos medidas razonables para mantener la aplicación segura y evitar el acceso no autorizado a la información. Actualmente la aplicación no mantiene una base de datos de información personal de los usuarios.

8. Privacidad de los niños

Fox Run no solicita deliberadamente información personal a los usuarios. Si en el futuro se incorporan funciones que recopilen información personal, esta política será actualizada antes de implementar dichas funciones.

9. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de Fox Run o cuando sea necesario para cumplir con las normas aplicables. La fecha de actualización aparecerá al principio de esta página.

10. Contacto

Si tienes preguntas sobre esta política de privacidad o sobre Fox Run, puedes ponerte en contacto con el desarrollador mediante los datos de contacto proporcionados en Google Play.
